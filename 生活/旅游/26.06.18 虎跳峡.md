# 行程
## plan A 极致特种兵（其实也还好）

| 时间                      | 行程                                             |
| ----------------------- | ---------------------------------------------- |
| 赶往机场                    | 7点左右去机场，或者提前一晚住机场附近，小冯倾向提前住附近，能7:30左右起床        |
| 2026.06.19T09:35起飞      | 杭州飞丽江，2026.06.19T09:35起飞，2026.06.19T13:05到达    |
| 2026.06.19T13:05到达丽江    | 到达丽江                                           |
| 2026.06.19T15:00到达纳西雅阁  | 出站半个小时，打车到达纳西雅阁1h，留半个小时buffer                  |
| 2026.06.19T18:00到达新茶马客栈 | 正式开始徒步，经历28拐，到达新茶马客栈；也许夜里能看星空。啊一定要新，老茶马客栈感觉不太行 |
| 2026.06.20T08:00重新出发    | 茶马客栈到halfway客栈，一段据说是精华；halfway到龙洞水瀑布，再到张老师客栈   |
| 2026.06.20T14:00下撤      | 准备回丽江                                          |
| 2026.06.20晚             | 丽江住宿，逛逛夜景                                      |
| 2026.06.21 返程           | CA8518，14:00起飞，17:10到达杭州                       |
好处：不要请假，正好搞定虎跳峡，顺道丽江转转
缺点：没住到halfway客栈，据说halfway客栈是日照金山最佳点。非要夜里赶到halfway客栈的话，夜路有一点危险；并且茶马客栈到halfway客栈是精华，夜里看不到了

## plan B 夕阳红观光团

| 时间                       | 行程                                                    |
| ------------------------ | ----------------------------------------------------- |
| 2026.06.18T17:15起飞       | 杭州飞丽江，2026.06.18T17:15起飞，预计要下午两点半左右出发，得请半天假           |
| 2026.06.18T夜里到达丽江        | 到达丽江                                                  |
| 2026.06.19T09:00出发徒步     | 吃个米线，打车去纳西雅阁。然后开始徒步                                   |
| 2026.06.19 晚上到达halfway客栈 | 正式开始徒步，经历28拐，到达茶马客栈，然后到达halfway客栈，挺多网红景点的这边；也许夜里能看星空。 |
| 2026.06.20T08:00重新出发     | halfway到龙洞水瀑布，再到张老师客栈                                 |
| 2026.06.20T14:00下撤       | 准备回丽江                                                 |
| 2026.06.20晚              | 丽江住宿，逛逛夜景                                             |
| 2026.06.21 返程            | CA8518，14:00起飞，17:10到达杭州                              |
优点：悠闲，慢慢走慢慢爬，没有天黑压力，老年人养生徒步节奏；能住到halfway，期待一下日照金山
> 但是其实日照金山非常难说，可能下雨也不一定有

缺点：要请半天假
